# 資料庫功能說明

本目錄的 `init.sql` 建立演唱會訂票系統所需的 PostgreSQL 資料表、初始資料、索引與約束，使用 `interviewworks_ticket` schema。

## 主要功能

- **會員與權限**：儲存會員資料、權限及驗證所需的金鑰資料。
- **活動管理**：儲存活動內容、分類與場次資料。
- **活動收藏**：記錄會員收藏的活動。
- **場次與座位**：管理場次容量、保留數、售出數，以及各場次座位的可用、保留、售出與封鎖狀態。
- **訂單管理**：儲存票券、座位、金額、付款期限及付款／取消時間，支援待付款、已付款、已取消與已逾期狀態。
- **訂位重試**：保存訂位識別碼、請求雜湊與首次成功結果，供後端辨識重複請求。
- **編號管理**：保存活動、場次與票券的編號資料。

## 資料一致性

- 以場次與座位組合唯一識別座位，並透過有效訂單座位唯一索引防止重複占用。
- 透過庫存約束，確保容量、保留數與售出數不為負，且保留數加售出數不超過容量。
- 配合後端交易，同步處理訂單、座位保留／釋放及庫存異動。
- 保存付款期限並建立逾期查詢索引，供後端掃描逾期訂單與釋放座位。
- 金額使用 `numeric(12,2)`；付款期限、付款時間及取消時間使用 `timestamptz`。

## 資料表對照

| 資料表 | 用途 |
| --- | --- |
| `permissions`、`user_data`、`secret` | 權限、會員與金鑰 |
| `activity`、`session`、`activity_favorite` | 活動、場次與收藏 |
| `ticket` | 票券訂單、金額與狀態 |
| `seat`、`session_seat` | 座位配置與場次座位狀態 |
| `booking_idempotency` | 訂位重試與首次成功結果 |
| `activity_sequence`、`session_sequence`、`ticket_sequence` | 活動、場次與票券編號 |
