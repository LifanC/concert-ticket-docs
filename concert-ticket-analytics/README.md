# Python 銷售分析

從 PostgreSQL 讀取訂單資料，統計各場次的已付款訂單數與金額，並自動產生 CSV 報表。

## 主要功能

- **自動產生報表**：Java 後端啟動完成後執行一次，預設每次完成後等待 30 分鐘再執行。
- **場次銷售統計**：每個場次列出已付款訂單數與金額；沒有已付款訂單的場次顯示為 0。
- **CSV 匯出**：報表存放於 `reports/`，檔名包含 UTC 時間，每次產生新檔；使用 UTF-8 BOM 編碼，可由 Excel 開啟。沒有場次時仍輸出欄位標題。
- **唯讀分析**：只查詢銷售資料，不修改訂單或資料庫結構，也不匯出姓名、Email 等個人資料。
- **執行紀錄與逾時處理**：使用獨立執行緒，不佔用訂單到期排程；預設超過 120 秒終止，失敗時記錄日誌並於下一次排程重試。

## 自動化流程

Java 後端啟動完成後，`SalesAnalyticsScheduler` 會在獨立執行緒上立即執行第一次分析。排程透過 `ProcessBuilder` 啟動 Python 的 `analyze.py`，並將 Java 使用的資料庫連線資訊傳入 Python，讓分析程式查詢相同的資料庫。

Python 會以唯讀方式查詢各場次的已付款訂單，計算訂單數與金額，並將結果輸出為帶有時間戳記的 CSV 報表。每次執行結束後，Java 預設等待 30 分鐘再啟動下一次分析，因此不需要人工定時執行指令，同一個 Java 程序內的分析工作也不會重疊執行。

Java 會檢查 Python 的執行結果，成功時記錄報表目錄，失敗時記錄錯誤狀態，並於下一次排程重新執行。Python 最新一次的執行輸出保存在 `reports/analytics-latest.log`。單次分析預設超過 120 秒會被終止，避免工作長時間停滯；分析失敗不會中斷購票流程。

自動分析會隨 Java 後端持續運作；Java 關閉時，排程及仍在執行的 Python 程序也會停止。報表每次都產生新檔，方便保留不同時間的銷售快照。

## 統計規則

- 只計算 `PAID` 訂單，排除待付款、取消、過期與已退款訂單。
- 訂單數依唯一的 `ticket.orderno` 計算；金額加總 `ticket.payprice`，保留十進位精度。
- 已付款訂單若缺少金額，會回報錯誤；金額為 0 的免費訂單可正常統計。
- 報表反映查詢當下的已付款訂單金額，不代表歷史收款、退款流水或會計淨營收。

## 報表欄位

| 欄位 | 說明 |
| --- | --- |
| 場次編號 | 訂單所屬場次 |
| 已付款訂單數 | 該場次目前狀態為 PAID 的訂單數量 |
| 已付款訂單金額 | 該場次已付款訂單的 payprice 加總 |

目前提供 CSV 報表，尚未包含 Vue 管理後台的統計頁面或圖表。

## 測試

在此目錄執行 `.\.venv\Scripts\python.exe -m unittest -v test_analyze`。
6 項測試涵蓋排除非 PAID 訂單、零營收／免費票、缺漏金額拒絕匯出、Decimal 精度、Excel BOM／公式字元與空報表。SQL 聚合規則使用記憶體 SQLite 固定資料；此測試不取代真實 PostgreSQL 連線與排程驗證。
