## Vue 專案建立流程

### 1. 查看 PowerShell 執行原則

```
Get-ExecutionPolicy -list
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
npm install -g @vue/cli
npm install @stomp/stompjs sockjs-client
vue create project_name
npm install
npm run dev
```
